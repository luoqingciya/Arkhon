## 3. M3 V1.0 内测 —— P0 功能完整（目标发布形态）

> 对齐策划书 §6「V1.0 · P0」+ §5 指标，逐项可测。

### 3.1 订阅与节点
- [ ] 订阅导入成功率 ≥ 95%（覆盖 hysteria2/vless/vmess/trojan/ss/tuic 等样本，中端机档位）
- [ ] 订阅自动刷新 + 配额展示（`subscription-userinfo`：已用/总量、到期倒计时）【P1】
- [ ] # 分享链接（v2rayN 风格 URI 列表）导入

### 3.2 隧道与保活
- [ ] VPN 单路径全量接管（VpnExtensionAbility 虚拟网卡 + 路由 + DNS）
- [ ] 保活专项落地（对照 §1 的 T3 产出）：长时任务基线 + 回收自恢复
- [ ] 断网重连自动恢复；Wi-Fi ↔ 蜂窝切换隧道不悬挂
- [ ] 真机连续运行 4h 不掉线（建议两轮：Wi-Fi / 蜂窝）

### 3.3 代理与规则
- [ ] 节点测速 + 选中高亮 + 按延迟排序
- [ ] 生效规则只读展示 + 命中统计（对接内核 `/rules` 数据面）
- [ ] 内置分流预设一键构建基础规则（直连/广告/流媒体/AI 等）
- [ ] 分流规则可视化编辑（对齐桌面端规则编辑器；成本高则先"预设 + 行级校验"）【P1】
- [ ] DNS 分流联动（nameserver/fallback/policy 可视化，VPN 路径下真实生效）【P1】

### 3.4 设置与体验
- [ ] 主题：提瓦特深色玻璃拟态 + 亮色，即时切换
- [ ] 语言：zh / en
- [ ] 日志导出（导出前脱敏：掩码密码/指纹串）
- [ ] 冷启动到可用（展示订阅列表）≤ 3s
- [ ] 发布命名/图标/简介规避代理高危词（参考 ClashNEXT→ClashBox，审核强约束）

### 3.5 质量与合规
- [ ] 单测 `@ohos/hypium` + Mock `@ohos/hamock` 全绿
- [ ] 真机双形态冒烟脚本化（安装 → 启动 → 导订阅 → 启停隧道 → 页面可达断言）
- [ ] CI 预检硬门槛：GitHub Actions 每次 push 跑 lint + 单测（hvigor 命令行）通过方可合并
- [ ] GPL 合规：随包附 arkhon-core 对应版本源码链接 + LICENSE 文本
- [ ] 隐私政策 / 使用信息文案起步即维护

> 出口：P0 功能完整 + 真机双形态冒烟通过 + 提审材料齐备 → **提交审核（M4）**。
